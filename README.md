# Сайт YMV Painting Lab

Статический сайт без сборки: загрузите содержимое папки на любой хостинг (index.html в корне).

```
index.html      — разметка страницы
css/styles.css  — стили (цвета и шрифты — в блоке :root в начале файла)
js/main.js      — скрипты; блок CONFIG в начале файла — все контакты и карта
img/            — фотографии (WebP)
```

## Что заменить перед запуском

Всё меняется в `js/main.js` → `CONFIG`:

| Поле | Сейчас | Что указать |
|---|---|---|
| `phone`, `phoneTel` | +7 (900) 000-00-00 — заглушка | реальный номер (второй — только цифры с +7) |
| `address`, `addressNote` | «Калининград, Центральный район» | точный адрес и подсказку по въезду |
| `coords` | [54.7246, 20.4826] — метка-заглушка | координаты мастерской: в Яндекс Картах ПКМ по точке → «Что здесь?» |
| `yandexOrgId` | пусто | ID организации из ссылки `yandex.ru/maps/org/.../ID/` — тогда метка откроет карточку YMV |
| `yandexApiKey` | пусто | бесплатный ключ «JavaScript API и HTTP Геокодер» на developer.tech.yandex.ru (укажите домен сайта) |
| `hours`, `hoursShort`, `hoursFooter` | Пн–Пт 10–20, Сб 10–18, Вс по записи — заглушка | реальный график |

Telegram (@YMVpainting) и Instagram (@ymv_39) уже указаны.

В `index.html` поправьте цифры блока «О компании»: **6+ лет, 800+ авто, 12 мес. гарантии** — это примеры. Цены в карточках услуг (80 000 ₽, 17 000 ₽, 15 000 ₽) взяты из публикаций Instagram.

## Фотографии

Сейчас в `img/` стоят фото-заглушки с Unsplash (свободная лицензия). Замените их фотографиями ваших работ с теми же именами файлов — вёрстка подстроится. Рекомендуемый размер: 1200–1600 px по длинной стороне, формат WebP или JPG.

## Темы

Сайт открывается в теме устройства (светлой или тёмной); кнопка с луной/солнцем в шапке переключает тему и запоминает выбор. Цвета обеих тем — в начале `css/styles.css` (блок `:root` и два блока тёмной темы).

## Карта

- Метка YMV и кнопка «Построить маршрут» открывают Яндекс Карты. На телефоне сначала открывается приложение Яндекс Карт (если установлено), иначе — браузерная версия.
- Маршрут строится от текущего местоположения пользователя до `coords`.
- Если Яндекс Карты не загрузились (нет интернета, блокировщик), показывается резервная карта со снимком OpenStreetMap для текущих координат-заглушки. После смены `coords` резервная карта показывает нейтральную подложку с меткой — можно заменить `img/map-fallback.webp` своим снимком и обновить `MAP_SNAPSHOT` в `main.js`.
